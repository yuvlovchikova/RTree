# Пространственные запросы с R-tree индексом

Учебный проект по алгоритмам и системному программированию: выполнение пространственных запросов пересечения по геометрии зданий с помощью R-tree индекса.

Программа читает полигоны зданий из shapefile, заменяет каждую геометрию её ограничивающим прямоугольником, добавляет прямоугольники в R-tree из Boost.Geometry и возвращает идентификаторы объектов, чьи bounding boxes пересекают заданную область запроса.

## Стек

C++ · Boost.Geometry · Boost R-tree · GDAL/OGR · пространственные индексы · shapefile

## Пайплайн

1. чтение прямоугольной области запроса из входного файла;
2. загрузка `building-polygon.shp` через GDAL/OGR;
3. вычисление envelope для каждого геометрического объекта;
4. добавление пар `(bounding rectangle, object id)` в R-tree с квадратичной стратегией разбиения;
5. выполнение пространственного запроса `intersects`;
6. сортировка и запись идентификаторов найденных объектов в выходной файл.

## Зачем здесь R-tree

При линейном поиске каждый запрос приходится проверять против каждого пространственного объекта. R-tree иерархически группирует близкие ограничивающие прямоугольники и позволяет отбрасывать целые области данных, которые заведомо не могут пересечься с окном запроса.

## Репозиторий

- `R_Tree/R_Tree.cpp` — полный пайплайн построения индекса и выполнения запроса;
- `R_Tree/data/` — геоданные проекта;
- `R_Tree/input/` и `R_Tree/output/` — примеры входных запросов и результатов;
- `R_Tree.sln` — решение Visual Studio.

## Контекст

Это архивный учебный проект, сфокусированный на пространственной индексации и низкоуровневой работе с геоданными, а не production-GIS приложение.
